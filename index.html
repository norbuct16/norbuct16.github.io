Featured project

Automated Vulnerability Assessment Platform

Innovation Central Canberra, in collaboration with Cisco and AlgoSec ; Jun to Aug 2025

Problem

Compiling device vulnerability and lifecycle reports across the network was a manual, multi-step process ; slow to produce and easy to get wrong, which delayed remediation decisions.

Approach

I worked on an automation pipeline that pulls data from Cisco and AlgoSec and compiles it into a single consolidated report, turning a manual process into a repeatable, scheduled one.

My role

As Project Development Intern, I worked across planning, delivery, and stakeholder engagement, and wrote the core automation logic.

Result

The project won Best Project across all Innovation Central Canberra teams and was selected as an AIIA ACT Finalist in the Student category.
